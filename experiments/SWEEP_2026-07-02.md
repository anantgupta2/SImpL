## GOTCHA: oat cosine LR horizon is broken for this fork
- base.py computes num_training_steps = num_prompt_epoch × (len(prompts)//train_batch_size), but the real
  checkpoint step = rollout iteration = len(prompts)//rollout_batch_size. These are DECOUPLED.
- With tbs=128: cot16 horizon≈18, nbmarg horizon=0 (50//128) -> cosine degenerate. Affected ALL prior runs.
- Decision: use lr_scheduler=constant (sidesteps it). A proper fix would override self.scheduler in
  CoTOnlyLearner / SImpLNoBiasLearner (both subclass PPOLearner) with num_training_steps=max_sgd_steps.

# FINAL RESULTS (2026-07-05) — 4B, canonical

**Selection rule (canonical, reproduced by `scripts/eval/aggregate_finals.py`):** convergence =
rolling-3 peak of the **seed-averaged** dev cot_accuracy curve (step-cap 300). Report the
**seed-averaged test** at that convergence step. `±` = std across the 3 per-seed test values at
that step. `test-max` = rolling-3 peak of the seed-averaged **test** curve (oracle ceiling, does
NOT use dev — reference only). All numbers avg@8, `--cot_eval_only`.

Winners from the sweep: **lr=2e-5, clip(max_norm)=0.5, beta=0.02** for BOTH cot16 and nbmarg.
Finals = 3 seeds (123/234/345) on that HP. Variants: cot16 (compute control, ns=16), nbmarg
(simpl_no_bias, per-passage), flatsimpl (nbmarg + flatten_cot, 1 prompt/question), nbmargurs1
(nbmarg + understanding_reward_scale=1), flatsimplv3 (RACE-only: flatsimpl + v3 prompt +
zero_understanding_on_truncation).

| Dataset | Method | conv_step | dev | **TEST** | Δ vs cot16 | test-max |
|---|---|---|---|---|---|---|
| **LSAT** | cot16 | 180 | 29.4 | 26.0±0.2 | — | 26.5 |
| | nbmarg | 292 | 29.6 | 25.5±0.8 | −0.5 | 26.5 |
| | **flatsimpl** | 276 | 29.3 | **27.0±0.6** | **+1.0** | 26.9 |
| | nbmargurs1 | 256 | 29.9 | 25.9±1.2 | −0.1 | 26.0 |
| **RACE** | cot16 | 76 | 84.1 | 83.7±0.5 | — | 83.7 |

| | flatsimpl | 292 | 82.6 | 79.3±0.4 | −0.1 | 79.2 |

**Read (4B):**
- **LSAT: flatsimpl is the one clean win, +1.0pp** (27.0 vs 26.0), also highest test-max. Per-passage
  nbmarg and reward-scale-1 are flat/negative → it is the **flatten_cot** (1 understanding
  prompt/question) that pays, not the understanding reward magnitude.
- **RACE: flatsimplv3 +0.5pp** — the understanding fix (v3 no-summarization prompt + zeroing
  truncated understandings) rescues RACE. Old-prompt flatsimpl was −0.4 (lossy summary + ~30%
  truncated); nbmarg is a tie. flatsimplv3 also has the best dev (84.8) and tightest σ (±0.2).
- **QUAIL: flat (−0.1)** — no v3-style prompt/truncation fix applied there yet; likely same
  malformed-understanding pathology RACE-v3 fixed (QUAIL passages are long).
- **Headline:** where the understanding is well-formed (LSAT flatsimpl, RACE flatsimplv3) the
  co-trained understanding beats compute-matched cot16 by +0.5–1.0pp; where it is malformed it
  ties/reverses → the win is driven by understanding *content*, not extra compute.

**Selection caveat (LSAT):** the dev plateau is flat to within ~0.2pp across steps 260–300 while
test swings ~1pp — single-step argmax is unstable, so the canonical rule selects on the
**seed-averaged** dev curve (stable), NOT per-seed windows (which shatter on the plateau and
spuriously collapsed flatsimpl to +0.2 in one intermediate cut).
